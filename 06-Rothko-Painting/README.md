# Rothko Painting

Sexto projeto do curso **Responsive Web Design** do freeCodeCamp.

## Tecnologias

- HTML5
- CSS3

## Objetivo

Reproduzir uma pintura abstrata inspirada nas obras do artista Mark Rothko utilizando apenas HTML e CSS.

O projeto tem como foco a prática de técnicas de estilização e posicionamento de elementos na página.

Neste projeto foram trabalhados conceitos como:

- Estrutura HTML
- Seletores CSS
- Box Model
- `width` e `height`
- `padding`
- `margin`
- `border`
- `transform`
- `filter`
- `box-shadow`
- Cores e opacidade
- Posicionamento e composição de elementos
