# Nutrition Label

Oitavo projeto do curso **Responsive Web Design** do freeCodeCamp.

## Tecnologias

- HTML5
- CSS3

## Objetivo

Reproduzir uma tabela de informações nutricionais utilizando HTML e CSS, praticando técnicas de estilização e organização de conteúdo.

Neste projeto foram trabalhados conceitos como:

- Estrutura HTML
- Tipografia e fontes
- `font-weight`
- `font-size`
- `line-height`
- Bordas e divisores
- `padding` e `margin`
- Seletores CSS
- Classes
- Pseudo-classes
- Organização e alinhamento de elementos
- Box Model
- Flexbox
