# Registration Form

Quarto projeto do curso **Responsive Web Design** do freeCodeCamp.

## Tecnologias

- HTML5
- CSS3

## Objetivo

Praticar a criação e estilização de formulários HTML por meio de uma página de cadastro.

Neste projeto foram trabalhados conceitos como:

- Elementos de formulário
- Inputs
- Labels
- Radio buttons
- Checkboxes
- Textarea
- Select e options
- Atributos `required`, `type`, `name` e `placeholder`
- Organização e estrutura de formulários
- Estilização com CSS
- Espaçamento e layout
