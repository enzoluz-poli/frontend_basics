# Colored Markers

Terceiro projeto do curso **Responsive Web Design** do freeCodeCamp.

## Tecnologias

- HTML5
- CSS3

## Objetivo

Praticar os fundamentos de CSS por meio da criação de marcadores coloridos.

Neste projeto foram trabalhados conceitos como:

- Cores em CSS
- `rgb()`
- `rgba()`
- `linear-gradient()`
- Gradientes
- Opacidade
- Seletores CSS
- Box Shadow
