# Cat Photo Gallery

Sétimo projeto do curso **Responsive Web Design** do freeCodeCamp.

## Tecnologias

- HTML5
- CSS3

## Objetivo

Criar uma galeria de fotos de gatos utilizando HTML e CSS, praticando principalmente conceitos de layout e organização de elementos em uma página.

Neste projeto foram trabalhados conceitos como:

- Estrutura HTML
- Elementos semânticos
- Imagens
- Links
- Classes e IDs
- CSS Grid
- `grid-template-columns`
- `gap`
- Organização e alinhamento de elementos
- Responsividade
- Estilização de imagens
