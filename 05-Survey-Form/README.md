# Survey Form

Quinto projeto do curso **Responsive Web Design** do freeCodeCamp.

## Tecnologias

- HTML5
- CSS3

## Objetivo

Praticar a criação e estilização de um formulário de pesquisa, utilizando diferentes elementos de formulário e técnicas de organização de layout.

Neste projeto foram trabalhados conceitos como:

- Estrutura semântica de formulários
- `input`
- `label`
- `select`
- `option`
- `textarea`
- Radio buttons
- Checkboxes
- Atributos `required`, `name`, `value` e `placeholder`
- Organização de formulários
- Estilização com CSS
- Espaçamento e alinhamento
- Responsividade básica
